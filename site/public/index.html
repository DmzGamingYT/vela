Confidentialité

Vos pages
restent vos pages.

Pas de compte, pas de synchronisation, pas de serveur Vela. Le blocage se fait dans Chromium, avant que la requête ne parte. Les clés restent dans le trousseau du système.

  • Liste de blocage embarquée, compteur visible dans la barre d’adresse.
  • Caméra, micro, position et notifications refusés aux pages.
  • Clés API chiffrées par Keychain, DPAPI ou libsecret.

La journée

Votre journée,
dans la barre latérale.

Le brief du jour lit uniquement votre historique local et vos onglets ouverts. Il propose trois gestes : reprendre, finir, ou se concentrer. Pas de flux, pas de recommandation venue d’ailleurs.

  • Des notes Markdown, dans de vrais fichiers que vous possédez.
  • Un historique et un brief qui restent sur la machine.
  • La page reste ouverte pendant que la note s’écrit à côté.

Vela 0.1

Ce qui est déjà là.

Une version de travail, testée sur macOS. Voici le périmètre exact.

Navigateur

  • Espaces isolés par partition Chromium
  • Onglets verticaux, dossiers repliables
  • Glisser-déposer et épinglage
  • Vue scindée redimensionnable
  • Palette ⌘K pour tout atteindre

Agent & modèles

  • Démo locale sans réseau
  • Dix fournisseurs, clés dans le trousseau
  • Test de clé et erreurs lisibles
  • Sources choisies, étapes visibles
  • Rapport Markdown enregistré en note

Le reste

  • Brief du jour calculé localement
  • Notes Markdown dans de vrais fichiers
  • Bloqueur de publicités et traqueurs
  • Thèmes clair, sombre, système
  • Restauration de session et d’onglets

Cette page est une présentation : aucun installateur n’est encore distribué. Les builds macOS et Windows arrivent après la signature ; Windows et Linux restent en préparation.
