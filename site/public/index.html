Démonstration

Seize secondes, quatre gestes.

Pas de maquette, pas de montage : l’application enregistrée pendant qu’on ouvre la bibliothèque, les notes, puis qu’on passe en sombre depuis les réglages.

  1. 01

    Bibliothèque

    Marque-pages, téléchargements et historique dans une seule feuille, triés et cherchables.

  2. 02

    Notes

    Le panneau latéral garde la page en place : on écrit à côté, pas par-dessus.

  3. 03

    Apparence

    Clair, sombre, ou comme le système — et trois teintes d’accent, appliquées immédiatement.

  4. Enregistrement réel, sans accélération. Le curseur est le seul ajout.

01 — Garder

La bibliothèque remplace trois menus.

Marque-pages, téléchargements et historique vivent dans la même feuille, ouverte par ⌘⇧O. Chaque liste se trie, se cherche, et se range dans l’espace où vous êtes.

  • Marque-pages — un dossier par sujet, une icône par site.
  • Téléchargements — progression, destination, ce qui reste.
  • Historique — par jour, sans compte qui le recolle ailleurs.
Le chapitre complet

02 — Noter

La note s’écrit à côté de la page.

Le panneau s’ouvre à droite, la page reste lisible. Une note par page, un surlignage ancré au passage, et des fichiers sur votre disque : rien à synchroniser.

  • Ancrée — le passage surligné revient avec sa note.
  • Locale — des fichiers dans le dossier de données, pas un compte.
  • Recherchable — ⌘⇧F cherche dans toutes les notes.
Voir le chapitre

03 — Régler

Une palette pour tout, deux thèmes pour lire.

⌘K ouvre la palette : un onglet, un espace, un réglage, tout se trouve au clavier. L’apparence suit le système, ou prend parti — clair, sombre, avec la teinte d’accent que vous voulez.

  • Palette — une seule entrée pour naviguer, chercher, agir.
  • Thème — clair, sombre, système, sans redémarrage.
  • Teinte — indigo, ardoise, sable : toute la barre suit.
Tous les raccourcis

Le reste du temps

Réglé pour travailler, pas pour configurer.

  • Onglets verticaux

    Les titres se lisent en entier, les dossiers se plient, l’adresse reste au-dessus. La bande ne rétrécit jamais jusqu’à l’icône.

  • Espaces isolés

    Travail, personnel, études : chacun ses cookies, sa teinte, ses sites épinglés, son historique. Deux comptes sur le même site, sans fenêtre privée.

  • Notes et surlignages

    Une note par page, ancrée au passage, lue et écrite en fichiers sur le disque — pas dans un compte.

  • Bouclier

    Les requêtes arrêtées sont comptées dans la barre ; traduction, épingle et actions du site vivent au même endroit.

  • Agent en fil

    L’agent suit la page dans un fil latéral, sans masquer le travail en cours. Il ne part que sur demande, et avec votre clé.

  • Coup d’œil

    Un lien s’ouvre dans une carte posée sur la page : épingler, scinder, ouvrir. La page de départ reste au premier plan.

Sous le capot

Un navigateur, un dossier, aucun service.

Azimut est une application Electron : Chromium pour rendre les pages, et du code à nous autour. Tout ce qui est gardé l’est dans un dossier sur l’appareil.

  • Moteur

    Electron · Chromium

    Les pages sont rendues par Chromium, comme dans Chrome ou Edge. Les gestes, les raccourcis et la barre sont ceux d’Azimut.

  • Filtre

    Une liste native en Rust

    Le blocage des traqueurs s’exécute dans un module compilé, hors du JavaScript de l’interface : la liste reste sur l’appareil, les compteurs aussi.

  • Données

    Un fichier vela.json

    Espaces, onglets, favoris, historique et réglages dans un seul fichier lisible. Effacer le dossier efface tout ; rien n’en est copié ailleurs.

  • Licence

    MIT, sans palier

    Le code est public, les builds sont les mêmes pour tout le monde. Pas d’édition « pro », pas de fonction réservée à un abonnement.

Le tableau complet des flux

Plateformes

Trois systèmes, un fichier chacun.

Les mêmes fonctions partout ; seul l’emballage change. Les builds ne sont pas encore signés, d’où un clic de plus au premier lancement — la marche à suivre est aussi dans l’aide.

  • macOS Apple silicon et Intel

    Un .dmg universel, ou les archives .zip arm64 et x64. Sans certificat Apple : macOS 15 demande Réglages Système › Confidentialité et sécurité › Ouvrir quand même ; macOS 14 et moins, un clic droit puis Ouvrir.

  • Windows x64

    Un installateur .exe. SmartScreen affiche « Windows a protégé votre PC » : Informations complémentaires, puis Exécuter quand même. La mise à jour s’installe à la fermeture de l’app.

  • Linux x64

    Une .AppImage autonome, ou un paquet .deb pour Debian et Ubuntu. L’AppImage se remplace toute seule ; le paquet .deb s’installe à la main, avec apt install ./Azimut-….deb.

Au premier lancement

  1. Aucun compte, aucun formulaire : Azimut crée son dossier de données et s’ouvre sur l’accueil.
  2. Reprendre ses favoris depuis Réglages › Navigation : un navigateur installé, ou un fichier HTML.
  3. Le moteur par défaut est DuckDuckGo ; il se change dans les réglages, sans redémarrer.
  4. L’agent répond en démo locale sans clé ; une clé API se range dans le trousseau du système, jamais dans un fichier du dossier de données.

Mises à jour : l’app vérifie les versions peu après le démarrage, puis périodiquement. Windows et AppImage se remplacent seuls ; un .deb passe par apt, et un build macOS non signé se retélécharge.

Questions fréquentes

Ce qu’on demande avant d’installer.

Faut-il créer un compte ?

Non. Il n’y a ni inscription, ni synchronisation, ni serveur Azimut : les espaces, les onglets, les favoris et les réglages vivent dans un fichier sur votre disque, et les pages gardées s’exportent en HTML depuis Réglages › Navigation.

Où sont mes données ?

Dans le dossier de données de l’application : un fichier vela.json pour les espaces, les onglets, les favoris, l’historique et les réglages, et des fichiers pour les notes et les surlignages. Les clés API vont au trousseau du système. Effacer ce dossier efface tout ; rien n’en est copié ailleurs.

Qu’est-ce qui sort de la machine ?

Les pages que vous ouvrez, la recherche quand vous la lancez, la météo de l’accueil si elle est activée, et la vérification des mises à jour. Aucune mesure d’usage, aucun compte. Le détail requête par requête est dans la page confidentialité.

L’agent lit-il tout ce qui est ouvert ?

Non. Il ne lit que la page que vous joignez, au moment où vous le demandez. Sans clé, il répond en démo locale, sur l’appareil ; avec une clé, le contenu de la page jointe part vers le modèle choisi. Les modèles et ce qu’ils reçoivent sont détaillés dans la confidentialité.

Comment se passent les mises à jour ?

L’app vérifie les versions peu après le démarrage, puis toutes les trois heures, au retour de veille et au retour du focus. Windows installe à la fermeture, l’AppImage se remplace au redémarrage, un .deb s’installe à la main. Sur macOS, un bundle non signé ne se remplace pas tout seul : le .dmg se retélécharge.

Puis-je me connecter à Google ?

Google peut refuser l’identité d’un navigateur qui n’est pas Chrome. La connexion passe par le navigateur système, et Azimut n’importe jamais de cookies ; les favoris, eux, s’importent depuis Chrome ou Safari. La marche à suivre tient en trois lignes.

Et maintenant

Il n’y a pas de compte à créer.

Le fichier s’installe ou se lance selon la plateforme, et Azimut se souvient de vous sur cet appareil seulement.
