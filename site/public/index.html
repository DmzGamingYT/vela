Questions fréquentes

Ce qu’on demande avant d’installer.

Faut-il créer un compte ?

Non. Ni inscription, ni synchronisation, ni serveur Azimut : espaces, onglets et réglages vivent dans un fichier sur votre disque.

Où sont mes données ?

Dans le dossier de données de l’application — un vela.json et des fichiers pour les notes. Les clés API vont au trousseau du système. Effacer ce dossier efface tout.

Qu’est-ce qui sort de la machine ?

Les pages que vous ouvrez, la recherche lancée, la météo si elle est activée, les mises à jour. Aucune mesure d’usage. Le détail est dans la page confidentialité.

L’agent, les mises à jour, Google : trois autres questions

Il n’y a pas de compte à créer.

Le fichier s’installe ou se lance selon la plateforme, et Azimut se souvient de vous sur cet appareil seulement.
