Confidentialité

Ce qui reste ici, ce qui sort.

Aucun compte Vela, aucun serveur Vela, aucune mesure d’audience. Cette page liste les destinations que Vela contacte d’elle-même, et ce qu’elle envoie à chacune. La liste est celle du code : le test d’audit échoue dès qu’une adresse apparaît sans y figurer.

Sur votre appareil

Tout ce qui suit vit dans votre dossier de données. Rien de cette liste n’est envoyé à Vela : il n’existe aucun serveur Vela pour le recevoir.

Clés et comptes

Vela n’a pas de compte. La seule identité demandée est celle de votre fournisseur de modèle, si vous en branchez un.

  • Les clés vivent dans le trousseau du système, jamais dans un fichier du projet.
  • Un modèle local, Ollama ou un endpoint sur localhost, ne fait sortir aucune donnée.
  • En mode démo, aucun modèle n’est appelé : le rapport de l’agent est simulé sur place.
  • Une note vocale ne part vers un fournisseur distant qu’après votre confirmation explicite.

Ce qui ne sort jamais

  • Vos onglets, votre historique et vos espaces, sauf la page que vous ouvrez elle-même.
  • Vos notes, vos surlignages et vos enregistrements, hors transcription demandée.
  • Un identifiant d’utilisateur : il n’y en a pas.
  • Des mesures d’audience : aucun script de mesure n’est chargé par Vela.
  • Les icônes des sites ne passent jamais par un service tiers : la requête va au site concerné.

Les fichiers exacts et leur emplacement sont décrits dans le README du dépôt.
