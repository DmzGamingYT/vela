Aide

Installer, ouvrir, comprendre.

Les builds sont signés par personne : ni certificat Apple, ni certificat Windows. Cela change la première ouverture, et rien d’autre. Voici les étapes exactes.

macOS — ouvrir un build non signé

Le fichier Vela-0.3.13-universal.dmg couvre Apple silicon et Intel. Gatekeeper refuse la première ouverture parce que l’application n’est ni signée ni notarisée : c’est un choix assumé, il n’existe pas de certificat développeur Apple.

  1. Ouvrir le .dmg, puis glisser Vela dans le dossier Applications.
  2. Dans le Finder, faire un clic droit sur Vela et choisir « Ouvrir ».
  3. Confirmer « Ouvrir » dans la boîte de dialogue. Les fois suivantes, un double-clic suffit.

Si macOS refuse encore : Réglages › Confidentialité et sécurité, puis « Ouvrir quand même » à côté du message concernant Vela. Une installation silencieuse n’est pas possible sans signature.

Windows — SmartScreen

L’installateur .exe n’est pas signé par un certificat commercial. SmartScreen affiche donc un avertissement au premier lancement.

  1. Lancer Vela-0.3.13-x64.exe.
  2. Dans la fenêtre bleue, cliquer « Informations complémentaires ».
  3. Cliquer « Exécuter quand même », puis suivre l’installation.

Linux — AppImage ou .deb

L’AppImage se lance sans installation. Le paquet Debian convient à Debian, Ubuntu et leurs dérivés.

  1. AppImage : rendre le fichier exécutable, puis le lancer.
  2. Debian : sudo apt install ./Vela-0.3.13-amd64.deb.
  3. Les mises à jour automatiques concernent l’AppImage et les builds macOS et Windows ; un paquet .deb se remplace à la main.

Connexion Google

Google peut refuser l’identité d’un navigateur qui n’est pas Chrome. Ce n’est pas un réglage à activer : la parade est de reprendre une session existante.

  • Importer une session depuis Chrome ou Safari, puis ouvrir Google dans l’espace concerné.
  • Pour un « Se connecter avec Google » sur un site tiers, ouvrir cette connexion dans le navigateur système.
  • Vela n’imite pas Chrome au-delà de ce qui est nécessaire : se faire passer pour un autre navigateur casse d’autres sites.

Extensions et synchronisation

Les extensions du Chrome Web Store ne sont pas prises en charge. La synchronisation de compte Vela n’existe pas non plus : il n’y a pas de compte. Vos espaces, vos notes et vos réglages restent dans le dossier de données de la machine, décrit sur la page Confidentialité.

Mises à jour

Vela vérifie les versions douze secondes après le démarrage, puis toutes les trois heures, au retour de veille et au retour du focus. Sur macOS, l’installateur de la nouvelle version est téléchargé en arrière-plan. Rien ne s’installe sans que la version soit téléchargée en entier.

Depuis la 0.3.9, une installation existante reçoit les versions suivantes sans réinstallation. Le contrôle auprès de GitHub est décrit ligne par ligne sur la page Confidentialité.
